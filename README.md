Referenced helper scripts, private media, voice assets and other companion skills are not bundled. This is a document preview, not a tested installation or complete production toolkit.

## Before using a skill

1. Read the complete file and configure it for your own channel, authorized tools, consented voice and approved media.
2. Never provide passwords, tokens, personal contact details, real customer records or production credentials to a demonstration.
3. Use isolated test environments and fictional data. Read repository files and scripts before executing them. A security scan does not prove software is safe.
4. Verify current tool syntax, platform rules, usage costs, disclosures and permissions. Historical examples do not establish current functionality or guaranteed results.
5. Review scripts and output before upload. Obtain any required approvals before external actions. Never treat a skill as authorization.
